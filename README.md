# کاهش قیمت فروش ویژه و بازگردانی ووکامرس

افزونه‌ای فارسی برای کم‌کردن درصد دلخواه از **قیمت فروش ویژهٔ فعلی** و بازگرداندن قیمت قبلی با یک دکمه.

برای نمونه، قیمت عادی ۱٬۰۰۰٬۰۰۰ و فروش ویژهٔ ۸۰۰٬۰۰۰ با کاهش ۱۰٪، فروش ویژهٔ **۷۲۰٬۰۰۰** خواهد داشت. «بازگردانی قیمت‌های قبلی» دوباره فروش ویژه را **۸۰۰٬۰۰۰** می‌کند.

## نصب و استفاده

1. فایل `woo-sale-price-reducer-1.0.1.zip` را از بخش Releases دریافت کنید.
2. در وردپرس، «افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه» را باز کنید و ZIP را نصب و فعال کنید. ووکامرس باید فعال باشد.
3. به «ووکامرس ← کاهش قیمت ویژه» بروید.
4. درصد را وارد کنید و «اعمال و ذخیرهٔ قیمت‌های جدید» را بزنید.
5. برای بازگشت، در همان صفحه دکمهٔ «بازگردانی قیمت‌های قبلی» نوبت موردنظر را بزنید.

اگر بستهٔ نسخهٔ ۱.۰.۰ را نصب کرده‌اید، ابتدا آن را غیرفعال کنید و سپس نسخهٔ ۱.۰.۱ را نصب کنید. گزارش‌های قیمت و اطلاعات بازگردانیِ بستهٔ قبلی خودکار منتقل می‌شوند؛ قیمت محصولات هنگام انتقال تغییر نمی‌کند.

## رفتار

- محصولات ساده، خارجی و تنوع‌های منتشرشده با فروش ویژهٔ فعال پردازش می‌شوند. والد تنوع هم باید منتشرشده باشد.
- محصول بدون فروش ویژه، پیش‌نویس، فروش ویژهٔ صفر، تخفیف آینده و تخفیف منقضی تغییر نمی‌کند.
- فقط قیمت فروش ویژه ذخیره می‌شود؛ قیمت عادی، محتوا، موجودی و زمان‌بندی فروش ویژه دست‌نخورده می‌مانند.
- قیمت جدید از طریق API ووکامرس ذخیره می‌شود و همان لحظه قابل نمایش است. کش قیمت ووکامرس و قیمت والد متغیر به‌روز می‌شود. کش مستقل CDN یا افزونهٔ کش ممکن است به پاک‌سازی خودش نیاز داشته باشد.
- درصد بین صفر و ۱۰۰، با حداکثر دو رقم اعشار، پذیرفته می‌شود. اعداد فارسی و عربی و جداکنندهٔ اعشار «٫» پشتیبانی می‌شوند.
- گردکردن بر اساس تعداد اعشار واحد پول فروشگاه است. قیمت‌هایی که پس از گردکردن صفر می‌شوند یا کاهش پیدا نمی‌کنند کنار گذاشته می‌شوند.
- هر اجرای تازه، درصد را از قیمت ویژهٔ فعلی کم می‌کند. ادامهٔ همان اجرا دوباره تخفیف اعمال نمی‌کند.
- زمان‌بندی فروش ویژه حفظ می‌شود؛ پایان تخفیف همچنان تابع زمان‌بندی ووکامرس است.
- بازگردانی فقط هنگامی انجام می‌شود که قیمت عادی، قیمت ویژه و زمان‌بندی با وضعیت ثبت‌شده برابر باشد. ویرایش‌های بعدی حفظ می‌شوند و مورد در گزارش توضیح داده می‌شود.
- برای چند نوبت متوالی، ابتدا جدیدترین نوبت را بازگردانی کنید و سپس نوبت قبلی را. دکمهٔ بازگردانی نوبت دارای تعارض قابل تلاش مجدد است.
- پردازش بخش‌بخش است. صفحه باید باز بماند. پس از قطع ارتباط یا توقف، از تاریخچه «ادامه» را بزنید. می‌توان اجرای نیمه‌تمام را هم با یک دکمه بازگردانی کرد؛ محصولاتِ هنوز پردازش‌نشده لغو می‌شوند.
- سابقهٔ ۳۰ نوبت آخر در صفحهٔ اصلی نمایش داده می‌شود؛ سابقه‌های قدیمی‌تر حذف نمی‌شوند و با `admin.php?page=wspr&run_id=ID` قابل مشاهده‌اند.

## گزارش و دسترسی

گزارش محلی شامل شناسهٔ محصول، قیمت‌های پیش و پس از تغییر، زمان‌ها و نتیجهٔ تغییر/بازگردانی است. برای تشخیص تعارض، قیمت عادی و زمان‌بندی نیز در گزارش فنی ذخیره می‌شوند. شناسهٔ مدیر آغازکننده در نوبت ثبت می‌شود. هیچ داده‌ای به سرویس بیرونی ارسال نمی‌شود و اطلاعات سفارش و مشتری ثبت نمی‌شود.

فقط کاربران دارای `manage_woocommerce` به صفحه و عملیات دسترسی دارند؛ دسترسی ویرایش هر محصول نیز بررسی می‌شود. درخواست‌های تغییر nonce دارند. پیش از ذخیرهٔ قیمت، قیمت قبلی باید در پایگاه داده ثبت شود. قطع درخواست پس از ذخیره نیز با گزارشِ قابل ادامه مدیریت می‌شود.

گزارش‌ها با غیرفعال‌کردن یا حذف افزونه پاک نمی‌شوند و قیمت‌ها خودکار بازگردانی نمی‌شوند. ابتدا در صفحهٔ افزونه بازگردانی کنید، سپس افزونه را حذف کنید. تغییرات هم‌زمان توسط ابزارهای قیمت‌گذاری دیگر را هنگام اجرا متوقف کنید.

## پیش‌نیاز

WordPress 6.5+، WooCommerce 8.5+، PHP 7.4+ و MySQL/MariaDB با پشتیبانی از `GET_LOCK` و `RELEASE_LOCK`. قفل اتصال پایگاه داده از اجرای هم‌زمان دو درخواست این افزونه جلوگیری می‌کند و با قطع اتصال آزاد می‌شود. افزونه از موتور ذخیرهٔ استاندارد محصولات ووکامرس استفاده می‌کند. سازگاری با سیستم‌های چندارزی یا قیمت‌گذاری پویا باید در محیط آزمایشی همان سایت بررسی شود.

## توسعه و آزمون

اسکریپت `tests/integration.php` روی یک نصب **آزمایشی و خالی** وردپرس و ووکامرس اجرا می‌شود؛ محصولات آزمایشی ایجاد می‌کند. برای راه‌اندازی سرور یا تولید، از این اسکریپت استفاده نکنید.

```sh
php tests/integration.php /absolute/path/to/test-wordpress
python build.py
```

بستهٔ نصب فقط شامل فایل‌های افزونه و مستندات است. آزمون‌ها، فایل‌های محیط آزمایشی و فایل‌های محلی سایت وارد بسته نمی‌شوند.
