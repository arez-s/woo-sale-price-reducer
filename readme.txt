کاهش درصدی قیمت فروش ویژهٔ فعال ووکامرس، گزارش قیمت و بازگردانی با یک دکمه.

== Description ==
قیمت ویژهٔ ۸۰۰ با ۱۰٪ کاهش به ۷۲۰ می‌رسد. با دکمهٔ بازگردانی دوباره ۸۰۰ می‌شود.
محصولات بدون فروش ویژهٔ فعال تغییر نمی‌کنند. محصولات ساده، خارجی و تنوع‌های منتشرشده پشتیبانی می‌شوند.
گزارش پیش از تغییر قیمت ثبت می‌شود. پردازش بخش‌بخش، ادامه پس از قطع ارتباط و حفظ تغییرات بعدی هنگام بازگردانی فراهم است.
صفحهٔ افزونه در ووکامرس ← کاهش قیمت ویژه قرار دارد. هنگام پردازش صفحه را باز نگه دارید.
قیمت عادی، محتوای محصول، موجودی و زمان‌بندی فروش ویژه تغییر نمی‌کند.
گزارش‌ها هنگام حذف افزونه حفظ می‌شوند. برای بازگردانی قیمت‌ها، پیش از حذف از دکمهٔ بازگردانی استفاده کنید.
راهنمای کامل در README.md است.

== Installation ==
1. ZIP را از افزونه‌ها ← افزودن افزونه ← بارگذاری نصب و فعال کنید.
2. ووکامرس باید فعال باشد.
3. از ووکامرس ← کاهش قیمت ویژه استفاده کنید.
